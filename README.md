# Bozo Executer

![platform](https://img.shields.io/badge/platform-macOS%20arm64-black)
![runtime](https://img.shields.io/badge/runtime-.NET%208-512bd4)
![status](https://img.shields.io/badge/status-alpha-orange)

A terminal Roblox executor for Apple Silicon Macs. Injects `bozo.dylib` into
the live client over a Unix socket and drives it from a Spectre.Console TUI.
